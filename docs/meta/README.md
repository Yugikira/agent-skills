# Meta Skills Documentation

Promoted meta-skills that maintain, verify, refine, and A/B test this repository. Mount them locally inside this repo with `python3 scripts/install_skills.py mount-local`.

## User-invoked

- [skill-mode](skill-mode.md) ([SKILL.md](../../skills/meta/skill-mode/SKILL.md)): Sticky router matching any skill-repo task to a playbook and core principles.
- [verify-skills](verify-skills.md) ([SKILL.md](../../skills/meta/verify-skills/SKILL.md)): Static linting, link checks, invocation parity, and live script smoke tests.
- [refine-skill](refine-skill.md) ([SKILL.md](../../skills/meta/refine-skill/SKILL.md)): Single-hypothesis hillclimb and no-op pruning loop.
- [ab-eval-skill](ab-eval-skill.md) ([SKILL.md](../../skills/meta/ab-eval-skill/SKILL.md)): Blinded A/B evaluation workflow with sanitized workspaces, hidden rubrics, and transcript audits.

## Model-invoked

- [writing-for-agents](writing-for-agents.md) ([SKILL.md](../../skills/meta/writing-for-agents/SKILL.md)): Reference for authoring and pruning any agent-facing document (`SKILL.md`, `AGENTS.md`, specs, prompts).
