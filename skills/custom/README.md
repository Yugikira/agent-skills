# Custom Skills

Promoted domain skills live here after passing `scripts/verify_repo.py` and verification against real examples or blinded A/B evaluation. Related skills may be grouped 1 level deep (`skills/custom/<group>/<skill>/`); standalone skills live directly under `skills/custom/<skill>/`.

## Domain Groups

- [kb-skills](../../docs/custom/kb-skills/README.md) (`kb-skills/`): Academic Markdown Knowledge Base suite (`kb-ingest`, `kb-query`, `kb-lint`, `kb-consolidate`).

## Standalone Skills

None yet. Standalone skills that do not belong to a multi-skill domain group are listed here under `User-invoked` or `Model-invoked`.
