# Meta Skills

Promoted skills that manage, verify, refine, and A/B test this repository.

## User-invoked

- [skill-mode](skill-mode/SKILL.md): Sticky router matching skill-repo tasks to playbooks and principles.
- [verify-skills](verify-skills/SKILL.md): Static and live verification gate for all skills, docs, and eval suites.
- [refine-skill](refine-skill/SKILL.md): Hypothesis-driven hillclimb and no-op pruning loop for improving an existing skill.
- [ab-eval-skill](ab-eval-skill/SKILL.md): Blinded A/B evaluation workflow with sanitized workspaces, hidden rubrics, and transcript audits.

## Model-invoked

- [writing-for-agents](writing-for-agents/SKILL.md): Core authoring reference for `SKILL.md`, `AGENTS.md`, and agent-facing prompts.
